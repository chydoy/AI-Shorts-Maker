# Реализация задач Влада Решетова

В архив внесены две задачи:

## 1. Smart Crop
- Добавлен `smart_crop.py`: MediaPipe Face Mesh обнаруживает лица через OpenCV, простое сопоставление координат связывает наблюдения между кадрами, размер лица и изменение расстояния между губами помогают выбрать вероятного говорящего.
- Координата окна кадрирования сглаживается EMA и передаётся в FFmpeg как динамическое выражение `crop`, после чего видео масштабируется до `1080x1920`.
- Если лицо не найдено или детекция недоступна, используется стабильный центральный crop, чтобы не останавливать рендеринг.
- В пайплайн добавлено скачивание исходного видео. Аудио извлекается из него через FFmpeg, чтобы не скачивать один и тот же ролик дважды.
- Добавлены зависимости MediaPipe, OpenCV и NumPy; Docker-образ получает системные библиотеки для OpenCV.

## 2. Прогресс-бар и стадии
- Frontend опрашивает `GET /api/v1/tasks/{task_id}/status` раз в 2 секунды.
- Добавлена шкала `0–100%` и четыре стадии: загрузка, транскрибация, анализ LLM, нарезка FFmpeg.
- Состояния отображаются цветами: серый — ожидание, синий с пульсацией — работа, зелёный — завершено, красный — ошибка.
- При ошибке выводится `error_message` от backend.

## Проверка
Из корня проекта:

```powershell
python -m unittest discover -v
```

Для пересборки Docker после изменения зависимостей:

```powershell
docker compose up --build -d
```

Затем открыть `http://localhost:3000`.

Примечание: для реального Smart Crop нужен доступ к YouTube и успешная загрузка исходного видео. Если лица не обнаруживаются, применяется центральное кадрирование. Точность выбора говорящего зависит от качества видео и видимости лица.
